#SCHOOL RESULT MANAGEMENT SYSTEM DATABASE (Project still ongoing)

PROJECT OVERVIEW:
This project involves designing and managing a relational database for a school result management system. It focuses on organizing academic records and supporting efficient retrieval and analysis of student results using Python + MySQL.

Situation: Managing teachers, parents, admin and student records, subjects, examinations, academic sessions, and results requires a structured system to maintain data consistency and make academic information easier to retrieve.

OBJECTIVE: 
Design and implement a relational database that organizes school records and supports queries for retrieving, calculating, and analyzing student results.

WHAT I AM DOING: 
1. Designed a MySQL database with related tables for students, teachers, subjects, classes, examinations, academic years, report cards, and examination results. 
2. Then, connected the database to python through PyMySql on VSCode for easy access on the web back-end systen.
3. System views, functions, triggers and procedures is currently ongoing....
3. Currently developing SQL queries that would retrieve student records, calculate scores and averages, determine grades, rank students, and generate academic summaries for report card checking and generation. 
4. Dummy data will be inserted for testing and demonstrating the database functionality.

RESULT: 
The database would provide a structured approach to managing academic records and supports efficient querying and reporting of student performance.

Tools: MySQL, MySQL Workbench, SQL, and Python (PyMySQL)

PROJECT PHASE:
Phase 1 - MVP Core (10 tables): I started with this to get the core relationship working
(view 10 table blueprint and ER diagram)

Phase 2 - Full Productions (33 tables): Then Extended and added more entities for real school use-case.

Phase 3 - Created "views": to calculate result totals easily

Phase 4 - (Currently working on system functions, procedures, and triggers)

KEY FEATURES (Iterating feature):
1. Relational database design.
2. Structured academic record management.
3. Student result retrieval.
4. Grade and average calculations.
5. Student ranking queries.
6. Academic performance summaries.
7. SQL queries for reporting and analysis.
8. Dummy data for testing and demonstration.
